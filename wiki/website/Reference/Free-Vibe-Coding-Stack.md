# Free Vibe Coding Stack

> Complete zero-budget tool ecosystem for building and deploying a cinematic portfolio website.

---

## Code Editor + AI

| Tool | What It Does | Free Tier |
|---|---|---|
| **VS Code** | Code editor | ✅ Free |
| **Continue.dev** | Open-source AI agent in VS Code. Like Cursor but free. Connect any model. | ✅ Free |
| **GitHub Copilot** | AI autocomplete + chat | ✅ Free (2K completions/mo, 50 chats/mo) |
| **OpenCode CLI** | Terminal AI agent (DeepSeek V4 Flash Free) | ✅ Free |

## Complete Free Workflow

```
DESIGN
├── Figma (free) → design your sections
├── Godly (free) → inspiration gallery
├── Refero (free) → design research
├── Glif (free) → AI hero/bg images

BUILD
├── VS Code + Continue.dev (free) → main editor
├── OpenCode CLI (free) → AI agent for docs/git
├── GitHub Copilot (free tier) → AI autocomplete
├── Next.js 15 + shadcn/ui (free) → framework + UI

ANIMATE
├── Lenis (free) → smooth scroll
├── Motion.dev (free) → scroll + UI animations
├── GSAP (free) → complex scroll sequences
├── React Bits (free) → pre-built text reveals
├── Aceternity UI (free) → hero/bento grids

HOST
├── GitHub (free) → source code
├── Vercel (free) → deploy on git push
├── Vercel Analytics (free) → traffic insights
├── Sentry (free) → error tracking
├── Tally (free) → contact form
```
