# Glossary

Common terms and acronyms used throughout this wiki.

---

## A

**Anime.js** — JavaScript animation engine. Framework-agnostic, modular, v4 rewrite in 2025. [[Anime.js]]

**Awwwards** — Awards for the best web design. Winning sites are the benchmark for cinematic quality.

## B

**Base UI** — Unstyled headless React component library. Now the default base for [[shadcn-ui]] (as of July 2026).

**Bundle size** — The file size of a library after minification and gzip compression. Smaller = faster page loads.

## C

**Cinematic website** — A website designed to feel like a film experience: smooth scrolling, timed reveals, parallax depth, narrative-driven scrollytelling, ambient motion.

**CLI** — Command Line Interface. Used to install shadcn components, 21st.dev components, and UI UX Pro Max.

## D

**Design tokens** — Named values for design properties (colors, spacing, fonts, easing curves). Used by design systems to maintain consistency.

**dotLottie** — Compressed evolution of the Lottie format. Uses ZIP compression, supports multiple animations and themes in one file. [[Lottie]]

**DX** — Developer Experience. How pleasant/efficient a tool is to use.

## F

**Figma Motion** — Native timeline animation feature in Figma (launched June 2026). [[Figma-Motion]]

**Framework-agnostic** — A library that works with any JavaScript framework (React, Vue, Svelte, vanilla) without modification.

## G

**GPU-accelerated** — Rendering that happens on the Graphics Processing Unit rather than the CPU. Results in smoother, faster animations.

**GSAP** — GreenSock Animation Platform. Professional-grade JavaScript animation library with ScrollTrigger, SplitText, MorphSVG. [[GSAP]]

**gzip** — Compression algorithm. Bundle sizes are typically measured "gzipped" (after compression).

## H

**Hardware acceleration** — Using the GPU to render animations instead of the CPU. Motion.dev does this via native `ScrollTimeline` API.

## J

**Jitter** — Web-based motion design tool with AI agents, shaders, and Lottie export. [[Jitter-AI]]

## L

**Lenis** — Smooth scroll library. Under 4KB. Industry standard for buttery scrolling. [[Lenis]]

**Lottie** — Lightweight vector animation format. JSON-based. Playable via dotLottie web player. [[Lottie]]

## M

**MCP** — Model Context Protocol. A protocol that lets AI agents communicate with tools and services. Used by Figma Motion, Rive, shadcn, and 21st.dev to let AI agents access their capabilities.

**Motion.dev** — Animation library (formerly Framer Motion). Hardware-accelerated, React-first. [[Motion.dev]]

**MotionScore** — Performance grading system for Motion UI components (S through F).

## P

**Pinning** — GSAP ScrollTrigger feature. Locks a section in place while the rest of the scroll continues beneath it. Used for scrollytelling.

## R

**Radix UI** — Unstyled, accessible React component primitives. Previously the default base for shadcn/ui. Still supported.

**React Aria** — Adobe's accessible React component library. Now a first-class base option in shadcn/ui (July 2026).

**React Bits** — 140+ pre-built animated React components. [[React-Bits]]

**Registry** — A collection of components that can be installed on demand. Used by shadcn/ui and 21st.dev.

**Rive** — Interactive graphics engine with state machines. 120fps GPU-accelerated. Used by Spotify Wrapped. [[Rive-Engine]]

**Runtime** — A library that runs in the browser to render animations (e.g., dotLottie web player, Rive React runtime).

## S

**Scrollytelling** — Scroll-driven storytelling. A narrative that unfolds as the user scrolls down the page.

**Scroll-linked animation** — Animation values tied directly to scroll position (e.g., parallax, progress bars). [[Animation-Engine-Comparison]]

**Scroll-triggered animation** — Animation that fires when an element enters the viewport (e.g., fade in on scroll).

**ScrollTrigger** — GSAP plugin for scroll-driven animations. Supports pinning, scrubbing, and responsive breakpoints. [[GSAP]]

**shadcn/ui** — Not a package. A component system where source code is copied into your project. [[shadcn-ui]]

**ScrollSmoother** — GSAP's own smooth scroll plugin. Alternative to Lenis.

**SplitText** — GSAP plugin for character/word/line text animations. Now free.

**Spring physics** — Animation based on spring mechanics (stiffness, damping, mass). Feels natural and responsive.

**State Machine** — Rive's visual system for defining interactive animation behaviors (states, transitions, conditions). [[Rive-Engine]]

## T

**Tailwind CSS** — Utility-first CSS framework. Default styling approach for shadcn/ui, 21st.dev, and React Bits.

**Theme** — A cohesive set of design tokens (colors, fonts, spacing). shadcn/ui has 8 built-in themes.

**Three.js** — 3D JavaScript library. Used by Vanta.js for WebGL backgrounds. [[Vanta.js]]

**Tree-shakeable** — A library that only includes the code you actually import. Keeps bundle sizes small.

## U

**21st.dev** — Community registry of 10,000+ React + Tailwind components. AI-prompt installable. [[21st.dev]]

**UI UX Pro Max** — AI skill with design intelligence database (84 styles, 192 palettes, 74 fonts, 22 stacks). [[UI-UX-Pro-Max]]

## V

**Vanta.js** — One-line 3D WebGL background effects (waves, birds, globe). [[Vanta.js]]

**Variants** — Named animation states in Motion.dev. Propagate through the component tree for orchestration.

## W

**WAAPI** — Web Animations API. Native browser API for animations. Motion.dev uses it for hardware acceleration. Anime.js has a WAAPI variant.

**WebGL** — Web Graphics Library. JavaScript API for rendering 3D graphics in the browser. Used by [[Vanta.js]] and [[Rive-Engine]].

**WebGPU** — Modern GPU API (successor to WebGL). Used by the dotLottie player for hardware-accelerated Lottie rendering.

### A
**Aceternity UI** — 200+ Tailwind + Motion React components with micro-interactions. [[Aceternity-UI]]

### G
**Godly** — Curated gallery of exceptional web design. Filterable by tech and style. [[Godly]]

### M
**Mobbin** — 621K+ real app screenshots for design reference. MCP for AI agents. [[Mobbin]]

### R
**Refero** — Structured design reference library with DESIGN.md context extraction for AI. [[Refero]] — Web Graphics Library. JavaScript API for rendering 3D graphics in the browser. Used by Vanta.js and Rive.

**whileInView** — Motion.dev prop for scroll-triggered animations. Fires when element enters viewport.
