# Godly — Web Design Inspiration Showcase

> **Curated gallery of astronomically good web design.** Real websites, portfolios, brands, and interfaces. Filterable by category, technology, or style.

**Homepage:** https://godly.website
**Design:** https://godly.design
**Similar:** https://recent.design (same platform)
**Pricing:** Free
**Content:** Curated by editors, sourced from social media (X/Twitter)

---

## Overview

Godly is a curated gallery of the best web design on the internet. It's not a structured reference library like [[Mobbin]] or [[Refero]] — it's a **showcase of inspiring websites**. Each entry features a screenshot and link to the live site.

It's the closest thing to an "Awwwards feed" for quick daily inspiration.

---

## Key Strengths

- **High curation bar** — only the best designs make it in
- **Free** — no subscription, no paywall
- **Motion category** — directly useful for cinematic portfolio research
- **Tech filters** — find Next.js + GSAP sites specifically
- **Fresh** — new designs added regularly from social media
- **recent.design** — sister site, same content different layout

---

## Key Weaknesses

- **No structure** — screenshots only, no extracted styles or patterns
- **No search** — browse only (no search bar for specific patterns)
- **No AI integration** — no MCP, no API
- **Visual only** — no code, no design tokens, no references

---

## For a Cinematic Portfolio

Godly is **the best resource** for finding cinematic portfolio inspiration. Filter by:
- **Motion** → see the best animated websites
- **Next.js** → sites built with your target stack
- **3D** → WebGL and Three.js portfolio experiences

Browse these to understand what "cinematic" looks like in production. When you find a site you love, visit it and study:
- Scroll behavior
- Animation pacing
- Section transitions
- Typography choices
- Color palette
