# Mobbin — UI & UX Design Reference Library

> **The largest curated library of real app screenshots.** 621,500+ screens from 1,400+ iOS, Android, and web apps. Searchable by screen type, flow, and industry.

**Homepage:** https://mobbin.com
**MCP:** https://mobbin.com/mcp
**Figma Plugin:** Available in Figma Community
**Pricing:** Free (limited) / Pro $12/month / Team plans

---

## Overview

Mobbin is the most comprehensive design reference library available (2026). It contains 621,500+ screenshots and screen recordings from real shipped products. Every screen is manually categorized by screen type, UI element, user flow, and industry.

The core value: **instead of downloading apps and screenshotting flows yourself, search Mobbin and find exactly what you need in seconds.**

---

## Key Features

### 621,500+ Screens (and growing)
Every screen from 1,400+ apps and 200+ websites, curated and tagged.

### Flows
Full user journeys with interactive hotspots — go through an onboarding flow, checkout, or signup screen by screen. Includes micro-interactions and animations.

### Advanced Filtering
| Filter | Examples |
|---|---|
| **App** | fintech, health, e-commerce, social, travel |
| **Screen type** | onboarding, settings, search, checkout, profile, dashboard |
| **UI element** | bottom sheet, carousel, modal, skeleton, map |
| **User flow** | sign up, add to cart, search, filter, share |
| **Platform** | iOS, Android, Web |

### Figma Plugin
Copy designs directly into Figma — download or paste screens into your canvas.

### Collections
Save and organize references by project. Share collections with your team.

### MCP for AI Agents
Mobbin MCP connects your agent to the library. Agents can search for proven design patterns and apply them:

```
"Show me pull-to-refresh animation examples from social apps"
"Find 30 bottom sheet examples from top iOS apps"
"Get empty state patterns from fintech apps"
```

## Key Strengths

- **Largest library available** — 621K+ screens, unmatched scale
- **Flows with micro-interactions** — not just static screenshots
- **Figma plugin** — paste real designs into your canvas
- **MCP for agents** — AI research before AI building
- **Best filtering** — screen type + UI element + flow + industry
- **$12/month Pro** — affordable for regular use

---

## Key Weaknesses

- **Mobile-heavy** — strongest for iOS/Android apps, web coverage growing but thinner
- **Web coverage limited** — marketing sites, portfolio sites less represented
- **Subscription needed** — free tier very limited
- **Inspiration tool** — no code output, references only
- **Not for design systems** — shows screens, not component code

## For a Cinematic Portfolio

Mobbin is less directly useful for portfolio design (it's app-focused). Use it for:
- UI pattern research (navigation, interaction patterns)
- Mobile portfolio companion app design
- Design system references (colors, typography in real apps)

For web portfolio inspiration, prefer [[Godly]] or [[Refero]].
