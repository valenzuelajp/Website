# 21st.dev — Component Registry

> **10,000+ community-published React + Tailwind components.** AI-prompt installable. Built on shadcn/ui conventions.

**Homepage:** https://21st.dev
**GitHub:** https://github.com/21st-dev
**License:** Components are MIT (copied as source into your repo)
**Platform:** Free (2 component copies/day), paid for unlimited

---

## Overview

21st.dev is a community registry of React components and templates. Designers and engineers publish components they've built; you browse them, preview them live, and copy an AI-ready prompt that drops the component into your project through Cursor, Claude Code, v0, Lovable, or any AI agent.

Unlike a traditional component library (one package, one aesthetic), 21st.dev is a **registry**: many authors, many styles, and the code is **copied into your repo** rather than imported. You own it and can change it.

---

## How It Works

### For Consumers

1. Browse 21st.dev catalog (10,000+ components)
2. Click "Copy prompt"
3. Paste prompt into your AI agent (Cursor, Claude Code, OpenCode, etc.)
4. Agent installs the component into your project — wired to your stack

Or via CLI:
```bash
npx @21st-dev/cli add @author/component-name
```

Or via MCP — agents can search + install directly:
```
/ui create a sign up form
```

### For Publishers
Publish your own components via Studio UI or CLI:
```bash
npx @21st-dev/cli publish --public
```

Components can be:
- **Public** — visible in catalog
- **Unlisted** — installable by URL but hidden
- **Private** — scoped to your team

### Team Libraries
Publish private components scoped to your team. Agents install from your library:

```
npx @21st-dev/cli add @your-team/component-name?api_key=$API_KEY
```

---

## Relationship with shadcn

- Components are published in the **shadcn registry format**
- Built with **Tailwind CSS + Radix UI** (same stack as shadcn)
- Compose with **shadcn/ui primitives** and your design tokens
- Use `npx shadcn` CLI to install

---

## Key Strengths

- **10,000+ components** — huge variety, many authors
- **AI-native** — copy prompt, paste into agent, done
- **MCP support** — agents can search and install autonomously
- **You own the code** — copied as source, no dependency
- **Team libraries** — private component collections
- **Works with any AI agent** — Cursor, Claude Code, v0, Lovable, OpenCode

---

## Key Weaknesses

- **2 free copies/day** — need paid plan for heavy use
- **Quality varies** — community-published, some better than others
- **React + Tailwind only** — no Vue/Svelte/vanilla
